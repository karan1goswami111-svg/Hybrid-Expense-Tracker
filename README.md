# Hybrid Expense Tracker Machine

A powerful CLI-based Multi-User Expense Tracker built using Python and T-SQL (Microsoft SQL Server).

## 🚀 Features
- **Multi-User Architecture:** Secure data isolation and management using custom SQL server instances.
- **Automated CSV Reporting:** Exports monthly and yearly expense insights into standard CSV format using Python's built-in `csv` module.
- **Data Visualization:** Renders interactive spending trend graphs using Matplotlib.
- **Dynamic Budget Alerts:** Features a built-in "Dynamic Budget vs Expense Alert Calculation Engine" to prevent overspending.

## 🛠️ Tech Stack & Dependencies
- **Language:** Python 3.x
- **Database:** T-SQL (Microsoft SQL Server Express)
- **Libraries used:** 
  - `pyodbc` - For seamless Python to SQL Server database connectivity.
  - `csv` - For generating light-weight, structured financial data reports.
  - `matplotlib` - For generating statistical data charts.
